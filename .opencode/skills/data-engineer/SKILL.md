# Data Engineer Skill - Bookstore E-Commerce

## Core Capabilities
- **Catalog Ingestion**: ETL scripts to import large book datasets (CSV, JSON, ONIX XML publisher feeds) into PostgreSQL/Prisma.
- **Sales & Inventory Analytics**: Aggregating daily sales, bestseller rankings, revenue reports, and low-stock alerts.
- **Recommendation Engine Data**: Processing user purchase history and book ratings to power "Customers who bought this also bought" recommendations.
