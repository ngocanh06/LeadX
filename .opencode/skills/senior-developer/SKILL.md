# Senior Developer Skill - Bookstore E-Commerce

## Technical Stack & Best Practices
- **Framework**: Next.js 14 (App Router) with Server Components and Client Components where appropriate.
- **Styling**: Tailwind CSS with dark/light theme support, clean typography, and responsive grid layouts.
- **Database & ORM**: Prisma with PostgreSQL, type-safe queries, migrations, and seed scripts.
- **Key Features**: Home page, catalog & search, book detail page, cart & checkout, user profile/orders, and admin dashboard.
